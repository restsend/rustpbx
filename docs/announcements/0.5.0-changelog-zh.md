# RustPBX 0.5.0

> 单二进制、可编程的 Rust SIP PBX —— 面向 FreeSWITCH/Asterisk 用户与 Voice Agent 开发者的现代替代方案。

自 0.4.6 以来 **1,874 个提交 · 13 位贡献者 · 708 个文件变更**(2026 年 6 月 – 9 月)。升级前请先阅读[破坏性变更与升级指南](#破坏性变更与升级指南)。完整明细:[详细 changelog(英文)](0.5.0-changelog-en.md) · 叙事版公告:[0.5.0-release-zh.md](0.5.0-release-zh.md)

## 亮点

**媒体引擎全面重构** — 呼叫建立时延 ~6.4 ms(快 2.7 倍)· 同编解码零拷贝 fast-path 中继,单路仅 ~0.14% 核 / ~0.57 MB · WebRTC↔SIP 原生互通:800 路跨传输中继与 500 路 Opus↔PCMU 实时转码均 **0% 丢包** · 18,000 通电话浸泡测试内存平坦、无音频毛刺。

**5000 路并发全录音,不到 4 核** — CPS=200 呼叫风暴 + 全程立体声录音 + MySQL 话单:4,943 路并发录音稳态 ≈3.9 核,**0.00% 丢包**,数据库近乎空闲(2–4 QPS),4,980 个立体声 WAV(4.4 GB)零丢弃。容量经验值:**每路录音 ≈ 0.08 核**。

**队列与呼叫中心进入社区版** — 技能组路由与升级策略 · 并发拨打(先接先得)· 主管四件套 `listen`(监听)/ `whisper`(耳语)/ `barge`(强插)/ `takeover`(接管)· 坐席签入签出、话后处理、排队轨迹追踪。

**RWI 实时控制面,给 Voice Agent 的遥控器** — 早期媒体即可录音 · 盲转 REFER 失败自动 B2BUA 桥接兜底 · `voip_bridge:` 双向 PCM 实时音频流 · 会议 `create/add/remove/mute/end/merge` 命令族 · `call.transfer.replace`(RFC 3891)· `dtmf.collect` · `app.chain`。

**实时转写与预测外呼** — `GET /cc/calls/{call_id}/transcript` SSE,主/被叫双路独立 ASR(Deepgram 兼容协议,懒启动、不触碰媒体路径)· 本地 SenseVoice 离线转写 · `POST /ami/v1/outbound/dial` 一个请求发起外呼,SSE 实时回流事件,`on_answer` 可挂接后续动作。

**集群、容器与优雅关机** — 分布式会话注册表,控制请求自动转发到所属节点 · SIGTERM 先排水再退出,发版不丢单 · 录音/话单/信令直传 S3、会话注册表落共享 PostgreSQL/MySQL —— 加副本即扩容。

## 新功能一览

- **媒体**:新增 Opus、G.729 编解码,48kHz 电话事件 DTMF;视频 SDP 协商、re-INVITE 与载荷透传;按腿协商媒体 profile
- **队列/CC**:RFC 7433 UUI 呼叫关联;三方会议 RTP 桥接与会议房间 SIP 拨入;队列/IVR/中继/路由/ACL 可存数据库、控制台直接编辑
- **IVR**:统一 `StartApp` 应用编排 + 内置 IVR 流;步骤式 IVR 可交给外部 HTTP Provider 逐步决策;会话级 Fallback 自动接管;通话中录音分段
- **集群**:媒体锚定到呼叫属主节点;集群感知 AMI —— `GET /calls` 活跃呼叫查询、会话定位、日志查看器、远程 reload
- **RWI**:originate 可直出指定运营商中继并带坐席归因;所有呼叫事件附 root call identity,广播事件携带完整呼叫上下文
- **SipFlow/录音**:高吞吐采集(MTU 批量、SSRC 丢包报告);确定性 flush,通话结束即可查到尾部消息;话单 JSON/信令 JSONL 直传 S3/HTTP;控制台录音波形回放
- **控制台**:呼叫轨迹时间线 + 统一错误码参考页;中英双语界面;路由策略栈可视化与运行时排序(PATCH API);内置 Web 拨号盘与 JsSIP 软电话
- **认证**:OAuth2 风格 SSO 登录代理;JWT 快速注册(免 401/407 往返);in-dialog 认证缓存;AMI CIDR 白名单
- **路由/中继**:`parallel_fork` 并行呼叫 + `max_ring_time`;中继加权选择;OPTIONS 健康检查;按中继 `external_ip`/`bind_ip` 与网络 profile;CPS 与并发限流
- **转接**:弹性媒体桥上的交互式转接;可配置呼叫前转;队列转接携带 UUI 上下文,坐席接手不丢信息
- **NAT**:`sip_external_ip`、`auto_sip_external_ip`、`local_networks`、`[[network_profile]]`;标准化 SIP 错误码并注入呼叫轨迹
- **运维**:ACL/中继/路由/队列/IVR/TLS 证书热重载;控制台诊断工具箱(含路由评估器);`/metrics`(Prometheus)+ `/healthz`

## 破坏性变更与升级指南

### 录音与 SipFlow
- **只配 `[sipflow]` 不再自动捕获 RTP。** RTP 采集需要显式录音配置:

  ```toml
  [recording]
  enabled = true
  type = "sipflow"   # 仅信令采集的行为不变
  ```
- `callrecord` 存储默认改为 `type = "database"`(此前示例为本地 JSON 文件)。如需本地文件、S3 或 HTTP 上传,请显式配置 `[callrecord]`。
- 录音自动启动点可配置(回铃早期媒体 vs 应答后)。

### SIP 行为
- `session_timer` 默认改为**开启**(RFC 4028,Supported 模式);
- `video_codecs` 默认 `["H264", "VP8"]`;新增 `video_policy`(`pass_through` / `strip` / `transcode`);
- 新增 NAT/网络配置:`sip_external_ip`、`auto_sip_external_ip`、`local_networks`、`[[network_profile]]` —— 若依赖隐式默认值,请复查 NAT 配置。

### RWI 协议(变更最大)
- 事件改名:**`call_incoming` → `call_created`**;
- 删除命令:`media.stream_start` / `media.stream_stop` / `inject_start` / `inject_stop` —— 实时音频改用 `call.transfer` 到 **`voip_bridge:`/`bridge:` WebSocket 端点**(PCM16 二进制帧);`record.mask_segment` 删除;
- 删除事件:`dn_state_changed` / `dn_registered` / `dn_unregistered`、`call_metadata_updated`、`ivr_flow_transitioned`、`queue_overflowed`、`parallel_originate_*`、`session_resumed`、`media_stream_started`/`stopped`、`record.segment_masked`;
- **`record_stopped` 不再携带录音 URL** —— 改听 `record_end` / `recording_metadata_available`;
- 事件改名:`supervisor.takeover.completed` → `supervisor.takeover.started`;
- 参数变更:`call.originate`(移除 `hold_music`/`hold_music_target`)、`queue.enqueue`(移除 `skills`/`max_wait_secs`)、`conference.create`(移除 `backend`/`record`);
- 事件字段变更:移除 `ani`/`dnis`/`root_call_id`/`operation_id`;新增 `caller`/`caller_name`/`callee_name`/`trace_id`/`hangup_by`/`duration_secs`/`transfer_target`;
- 删除配置项 `[rwi].enabled`、`[rwi].contexts`;
- `[rwi.smart_routing]`、`[rwi.local_rules]`、`[rwi.sip_header_passthrough]` 已明确标注为**设计提案、未实现** —— 请勿依赖。

### 控制台 / HTTP API
- 所有控制台 JSON 端点统一挂到 **`/api` 前缀**下,经认证中间件 + CSRF 防护;新增静态 Bearer Token 认证(`[console].api_tokens`,带 scopes);
- `/licenses` 列表路由移除(`/licenses/verify` 保留);
- locator/注册数据结构变更:`aor` 变为完整 `IP:port` 地址,`destination` 带传输前缀,新增字段(`home_proxy`、`supports_webrtc`、`transport`、`user_agent`、`expires`)。

### 移除的组件与配置
- 移除 addon:`endpoint_manager`、`enterprise_auth`、`sbc`;
- 移除配置项:`[proxy].sip_flow_max_items`、`media_cache_path`;
- 移除 `verify-i18n` 二进制;新增 `rustpbx dump` 子命令(导出数据库 DDL);
- 删除 `opus` Cargo feature —— Opus 经 audio-codec 始终可用。

### 部署
- **源码构建现在必须带子模块**:`git clone --recurse-submodules`(addon `cc`、`wholesale`、`ivr_editor`、`telemetry`、`voicemail` 已改为 submodule);
- Docker 镜像:基底改为 `debian:trixie-slim`,不再需要 `libopus0`,sounds 移至 `/app/config/sounds`(保留 `/app/sounds` 兼容符号链接);
- 新增环境变量:`DEEPGRAM_API_KEY`(远端转写)、`CC_PHONE_AUTH_SECRET`(手机号认证)。

### 数据库
- 迁移在启动时自动执行(可用 `--skip-migrate` 跳过);本次新增三个:`outbound_sip_trunk_id` 话单列、`config_entries` 表(数据库配置)、`cluster_sessions` 表(集群会话注册表);
- 启动时自动清理并自愈陈旧迁移记录;
- 依赖栈升级:sqlx 0.8 → 0.9,sea-orm 1.1 → 2.0。
